# Definition of Ready (DoR)

| Dimensão | Status | Avaliação |
|---|---|---|
| Objetivo de negócio | 🟢 Completo | Objetivo e problema definidos |
| Usuários | 🟢 Completo | Perfis e responsabilidades conhecidos |
| Processo | 🟢 Completo | Fluxos ponta a ponta e exceções definidos |
| Escopo | 🟢 Completo | Escopo da primeira entrega delimitado |
| Regras de negócio | 🟢 Completo | Vagas, espera, pagamentos, cancelamento, reembolso e certificação definidos |
| Dados | 🟢 Completo | Dados principais e obrigatoriedade definidos |
| Integrações | 🟢 Completo | Integrações principais identificadas |
| Segurança | 🟢 Completo | Autenticação e sessão definidas |
| Critérios de aceite | 🟢 Completo | Fluxos principais possuem critérios testáveis |
| Requisitos não funcionais | 🟢 Completo | Performance, capacidade e disponibilidade definidas |
| Dependências | 🟢 Completo | Dependências críticas identificadas |
